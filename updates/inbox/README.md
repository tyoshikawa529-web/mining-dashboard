# Daily reviewed updates
Place reviewed JSON files in this folder with as_of, changes, market_changes and map_updates. Data must carry original HTTPS sources. Coordinates need precision and a HTTPS source in location_note. The scheduled GitHub Action validates incoming files, deduplicates by asset/event, archives each input in updates/processed, and publishes the dataset. Empty inbox means no changes. It does not independently research the news or scrape all commodity price feeds. For the deployment workflow, GitHub Settings > Pages > Build and deployment > Source must be **GitHub Actions**.
